GenLayer Intelligent Contract · Sourcify v2 · Consensus-Backed

Translate verified smart contracts into a capability profile other apps can consume.

TokenScope retrieves a contract's verified artifacts from the public Sourcify API v2 and uses GenLayer's decentralized AI-validator consensus to answer one question: what administrative and control capabilities does the verified source actually expose?

⚠️
TokenScope is not a security audit. It analyzes verified contract artifacts and identifies observable capabilities. It does not certify contract safety and cannot guarantee that hidden, unverified, off-chain, or indirect behavior does not exist. NOT DETECTED means "not evidenced in the analyzed artifacts" — never "impossible".
